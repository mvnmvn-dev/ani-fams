1. System Overview

FAMS replaces scattered emails, spreadsheets, and paper logs with one secure system for HQ, plant, warehouse, and field operations.

Main modules (sidebar):

  • Dashboard
  • Reservations
  • Visitors
  • Documents
  • Records (Retention)
  • Legal Cases
  • Contracts
  • Administration — User Management, Roles & Permissions, Audit Log (Admin only)
Key messages for stakeholders: Role-based access controls what each user sees. Every important action is logged. ARNEL AI assists with analysis — it does not auto-approve decisions.

3. Login & Security

Step-by-step: First Login

  1. Open the system URL (local or deployed instance).
  2. Enter email and password.
  3. If enabled, complete 2FA or email OTP verification.
  4. Land on the Dashboard.

Security Features

  • Session timeout after inactivity
  • Two-factor authentication (optional, from profile)
  • Password reset via email
  • Audit Log — who did what, when
  • Roles & Permissions — module-level control

Demo tip: Log in as Employee first, then Staff, then Admin to show different menus and action buttons.

5. Facilities Reservation

Path: Sidebar → Reservations

Demo Flow A — Employee Requests a Room

  1. Click New Reservation Request.
  2. Select facility (HQ Conference Room, Blending Plant Bay, Warehouse Staging, etc.).
  3. Enter purpose, start/end date and time.
  4. Optional: equipment add-ons, recurring booking.
  5. Click Check availability (ARNEL Smart Check) — shows conflicts and suggested rooms.
  6. Submit → status: Pending.

Demo Flow B — Staff Approves

  1. Log in as Staff.
  2. Open Reservations → Awaiting decision section.
  3. Click Approve or Reject.
  4. On approval: system generates QR check-in code.

Demo Flow C — Day of Event

  1. Open reservation → QR badge or check-in field.
  2. Scan or enter code → status: Checked-In.
  3. Advance: In Use → Completed, or mark No Show / Cancelled.

Additional features: Calendar views (Month, Week, Agenda), conflict detection with alternative rooms, maintenance blocks, waitlist, analytics, CSV/PDF export.

Pending → Approved → Checked-In → In Use → Completed ↘ Rejected / Cancelled / No Show

6. Visitor Management

Path: Sidebar → Visitors

Demo Flow A — Pre-register

  1. Click Pre-Register Visitor.
  2. Enter visitor name, company, host employee, scheduled time, purpose.
  3. Optional: photo, visit areas.
  4. Submit → status: Pending Approval.

Demo Flow B — Host Approves

  1. Host or staff clicks Approve.
  2. Status becomes Approved.

Demo Flow C — Check-in at Lobby

  1. Security/reception clicks Check In.
  2. System issues digital badge (QR, photo, host, expiration).
  3. Host receives arrival notification.
  4. On departure: Check Out.

Security features: Watchlist alerts, overstay detection, emergency on-site roster, NDA signature when required.

Registered → Approved → Checked-In → Checked-Out → Completed ↘ Denied (watchlist)

7. Document Management

Path: Sidebar → Documents

Demo Flow A — Upload

  1. Click Upload Document.
  2. Enter title, category, confidentiality level.
  3. Attach file and submit.
  4. ARNEL auto-classifies and summarizes the document.

ARNEL Document Intelligence

  • AI classification, summary, and tags
  • Re-analyze — refresh AI analysis
  • Correct classification — feedback to improve accuracy

8. Records Retention & Compliance

Path: Sidebar → Records

  1. Define retention policy — name, category, retention period, disposal action.
  2. Assign policy to document — link document, set start date.
  3. Monitor compliance dashboard — Compliant / Expiring Soon / Overdue.
  4. Compliance calendar — upcoming disposals.
  5. Legal holds — block disposal when a case is active.
  6. Disposal workflow — see lifecycle below.
  7. Automatic reminders at 90, 60, 30 days and on expiration.
Pending Disposal → Compliance Review → Legal Approval → Archived

9. Legal Management

Path: Sidebar → Legal Cases

Demo Flow — File and Manage a Case

  1. Click File Legal Case — enter title, type, risk level, counsel, opposing party, budget.
  2. Case number generated (e.g. LC-2026-xxxx).
  3. From case detail: add parties, link documents, milestones, deadlines.
  4. Log expenses, record outcomes, run conflict scan.
  5. Print or save PDF case report.

ARNEL legal assistant: Case summary, important deadlines, related document suggestions.

Open → In Progress → Closed / Won / Lost / Settled

10. Contract Management

Path: Sidebar → Contracts

  1. Click New Contract — title, counterparty, value, dates, type.
  2. Save as Draft → submit for review → approval chain → signature → Active.
  3. Monitor renewal alerts before expiration.
  4. Use AI clause extraction for renewal, termination, and payment terms.
Draft → In Review → Pending Signature → Active → Expired / Renewed / Terminated

11. Cross-Cutting Features

Notifications

Bell icon in top bar — reservation approved, visitor arrived, compliance alert, contract expiring. Click to jump to the related module.

ARNEL AI Assistant (Global)

  1. Click ARNEL button (bottom-right).
  2. Ask natural-language questions across modules.
  3. Use quick tools: Reserve, Document, Contract, Legal, Records.

Audit Trail

Path: Administration → Audit Log. Filter by module, user, date. Shows login, approve, upload, check-in, dispose, and more.

Exports

Most modules support Export CSV and Export PDF for reporting.

12. Administration (Admin Only)
